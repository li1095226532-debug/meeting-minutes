🎙️ 会议纪要助手

浏览器录音 → 语音转文字 → AI 自动生成结构化会议纪要，
无需安装 App，打开网页即用。

🎤 浏览器录音 📝 语音转文字 🤖 AI 总结 🌐 多语言 ⚡ 实时反馈
📂 查看 GitHub 仓库

✨ 功能特性

🎤

浏览器录音

基于 MediaRecorder API，支持暂停/继续，无需安装任何 App。

📝

语音转文字

支持本地 GPU 加速、CPU 模式、云端 API 三种后端，灵活适配。

🤖

AI 会议总结

调用 Claude API 自动提炼主题、讨论要点、决议和待办事项。

🌐

多语言支持

支持中文、英文，自动检测语言，通用场景全覆盖。

📂

文件上传

支持直接上传已有录音文件（webm / mp3 / m4a / wav）。

⚡

实时反馈

录音波形显示、计时器、处理进度提示，体验流畅。

🚀 快速开始

1

安装依赖

基础依赖 + 语音转文字引擎（三选一）

# 基础依赖（必装）
pip install fastapi uvicorn python-multipart python-dotenv anthropic

# 语音转文字（三选一）
pip install faster-whisper    # 推荐，GPU 加速
pip install openai-whisper    # 备选，CPU
# 或使用 OpenAI API（无需本地模型）
2

配置环境变量

创建 .env 文件并填写 API Key

cp .env.example .env
# 编辑 .env：填写 ANTHROPIC_API_KEY
3

启动服务

浏览器打开 http://localhost:8866

python server.py
# 浏览器打开 → http://localhost:8866

🔧 语音转文字后端对比

🔌 API 接口

方法 路径 说明
